# Datheon Python Programming Internship

## About
This repository contains Python projects completed as part of the Datheon Python Programming Internship.

## Projects

### Task 1: Hangman Word Guessing Game
A console-based word guessing game developed using Python. It allows users to guess a hidden word within a limited number of attempts.

**Technologies:** Python, Random Module

### Task 2: Automated File Organizer
A Python utility that automatically organizes files into different folders based on their file extensions.

**Technologies:** Python, os, shutil, pathlib

### Task 3: Customer Support Chatbot
A rule-based chatbot that responds to user queries using keywords and predefined responses. It includes fallback responses and exit commands.

**Technologies:** Python, Regular Expressions
